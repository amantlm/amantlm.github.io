Admin Login & TLM Upload

यह एडमिन पैनल का शुरुआती इंटरफेस है। इसे वास्तविक लॉगिन और वेबसाइट पर सुरक्षित रूप से TLM प्रकाशित करने के लिए backend से जोड़ना आवश्यक है।

महत्वपूर्ण सुरक्षा सूचना: अभी इस पेज में कोई वास्तविक authentication या GitHub publishing जुड़ी नहीं है। इसलिए यहाँ password डालने से login नहीं होगा और फ़ाइल चुनने से वेबसाइट पर publish नहीं होगी। सार्वजनिक HTML में GitHub token या admin password रखना सुरक्षित नहीं है।

1. Admin Login

वास्तविक उपयोग के लिए Supabase Auth (या समान सुरक्षित authentication service) कनेक्ट किया जाएगा।

2. नया TLM जोड़ें

यह फॉर्म भविष्य के upload workflow का नमूना है। Backend जुड़ने के बाद ही सामग्री लाइव होगी।

3. आगे क्या-क्या मैनेज कर सकेंगे?

✓ TLM HTML फ़ाइल अपलोड, शीर्षक/कक्षा/विषय और विवरण
✓ प्रकाशित TLM को edit, replace या unpublish करना
✓ होमपेज के टेक्स्ट, उद्देश्य, फीचर्स और संपर्क लिंक बदलना
✓ चित्र/थंबनेल लाइब्रेरी और TLM खोज/फ़िल्टर

इन सुविधाओं को सक्षम करने के लिए सुरक्षित backend, storage और publishing workflow सेटअप करना होगा।
